# Supplementary Material for WIFS 2026 submission

This repository contains full-resolution figures accompanying the paper "Enhanced image forensics through partial C2PA-based provenance information", submitted to WIFS 2026.

Included are:
- Full-resolution version of all plots presented in paper;
- Complete detectors performance on the shared data test set, summarized in the paper as aggregated scatter plots for conciseness;
- Full-resolution version of the visual example shown in the paper.
